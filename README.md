# AI Mock Interview

An AI-powered mock interview web application that helps users practice for job interviews with realistic, role-specific questions and instant AI-generated feedback — built entirely with **HTML, CSS, and JavaScript**.

## Overview

**AI Mock Interview** simulates a real interview experience directly in the browser. Users select a job role / domain, answer AI-generated questions (via text or voice), and receive instant, structured feedback on their responses — helping them build confidence and improve before the real thing.

---

## Features

- **AI-Generated Questions** — Dynamic, role-specific interview questions powered by an AI API
- **Voice or Text Answers** — Respond via microphone (Speech-to-Text) or by typing
- **Instant AI Feedback** — Get a score, strengths, and areas of improvement for every answer
- **Multiple Interview Categories** — Technical, HR, Behavioral, and role-specific tracks
- **Timed Questions** — Simulates real interview pressure with a countdown timer
- **Fully Responsive UI** — Clean, modern interface that works on desktop and mobile
- **Session Summary** — Review all questions, answers, and feedback at the end of the session

## Tech Stack

| Layer            | Technology                          |
|-------------------|--------------------------------------|
| Structure          | HTML5                                |
| Styling            | CSS3 (Flexbox / Grid, custom animations) |
| Logic / Interactivity | Vanilla JavaScript (ES6+)         |
| AI Integration     | REST API calls to an AI model (e.g. Gemini / OpenAI) |
| Speech             | Web Speech API (Speech-to-Text & Text-to-Speech) |

> No frameworks, no build tools — pure front-end web technologies.
